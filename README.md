A modern real-time chat application built with the MERN stack, powered by Socket.io for instant messaging, Zustand for global state management, and styled with TailwindCSS + DaisyUI for a clean, responsive design.

Stay connected with private chats, group conversations, and live user presence tracking — all in one place. 🚀

✨ Features

🔑 Authentication & Authorization – Secure login & signup.

💬 Real-Time Messaging – Instant delivery with Socket.io.

👥 Private & Group Chats – Create or join multiple conversations.

🟢 Online/Offline Presence – See who’s active in real-time.

⚡ Global State Management – Powered by Zustand.

🎨 Responsive UI – TailwindCSS + DaisyUI for beautiful design.

📱 Cross-Device Ready – Works seamlessly on desktop & mobile.

🛠️ Tech Stack

Frontend: React, TailwindCSS, DaisyUI, Zustand
Backend: Node.js, Express.js, MongoDB
Realtime: Socket.io
Database: MongoDB Atlas / Local MongoDB
